কোথাও কোনো নাম নেই, সবার পরিচয় শুধু “Anon 7F3A” এর মতো একটা random ID।

⚠️ শুরুর আগে একটা বড় সীমাবদ্ধতা

Internet ছাড়া phone থেকে phone-এ chat করার জন্য best package হলো nearby_connections (Google Nearby)। এটা নিজে থেকেই Bluetooth, BLE আর Wi-Fi hotspot বা Direct-এর মধ্যে যেটা ভালো সেটা বেছে নেয়। কিন্তু এটা শুধু Android-এ চলে।

  • iPhone-এ এর জায়গায় Multipeer Connectivity লাগবে।
  • Android আর iPhone একে অপরের সাথে offline chat করতে পারবে না। শুধু BLE দিয়ে এটা সম্ভব, কিন্তু সেটা খুব ধীর।
তাই আমার পরামর্শ: প্রথমে Android-only বানাও।

পুরো App Flow

১App খোলা Welcome screen

  • প্রথমবার খুললে একটা random ID তৈরি হবে (uuid)। এটা flutter_secure_storage-এ save থাকবে। নাম হবে “Anon ” আর ID-এর প্রথম ৪টা character।

২Bluetooth gate Bluetooth required screen

  • “Get started” চাপলে আগে আমাদের নিজেদের popup দেখাবে, তারপর system permission চাওয়া হবে:
    • Bluetooth: Scan, Advertise আর Connect
    • Nearby Wi-Fi Devices
    • Location (Android 11 বা তার আগের version-এ)
  • Bluetooth off থাকলে চালু করতে বলবে।

৩Deny করলে Permission denied screen

  • App আর এগোবে না, শুধু “Open settings” আর “Try again” button থাকবে।
  • App যখনই foreground-এ ফিরবে, permission আবার check হবে। চালানোর মাঝখানে কেউ Bluetooth বন্ধ করলেও এই screen-টাই চলে আসবে।

৪Home Chats screen

  • Chat list আসবে local database থেকে। কোনো server নেই।

৫Find nearby Nearby scan screen

  • একই সাথে startAdvertising আর startDiscovery চলবে। দুটোতেই নাম হিসেবে শুধু Anon ID পাঠানো হবে।

৬Pair Pair request screen

  • Pair চাপলে requestConnection যাবে।
  • দুই phone-এই একই ৪-digit code দেখাবে (Nearby থেকে পাওয়া authenticationDigits)।
  • দুজনেই Accept করলে local database-এ নতুন conversation তৈরি হবে।

৭Chat Chat screen

  • Message phone থেকে phone-এ যাবে byte payload হিসেবে। নিজের phone-এ save হবে, তারপর ack আসবে।
  • অন্যজন range-এর বাইরে থাকলে message pending থাকবে। আবার connect হলেই নিজে থেকে চলে যাবে।

৮Unpair Unpair screen

  • অন্যজনকে একটা unpair signal পাঠানো হবে, তারপর দুই phone থেকেই conversation, সব message আর pairing key delete হয়ে যাবে।
  • অন্যজন যদি তখন range-এর বাইরে থাকে, তাহলে আমার phone থেকে সাথে সাথে delete হবে। ওর phone থেকে delete হবে পরের বার connect হলে।

৯Settings

  • নতুন ID নেওয়া, Wi-Fi Direct on বা off, visible on বা off, App lock, আর “Erase everything”।
